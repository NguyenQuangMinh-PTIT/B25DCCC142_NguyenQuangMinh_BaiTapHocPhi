# B25DCCC142_NguyenQuangMinh_BaiTapHocPhi
# Bài tập Lập trình hướng đối tượng – Quản lý học phí

## Thông tin sinh viên
- **Họ và tên:** Nguyễn Quang Minh
- **Mã sinh viên:** B25DCCC142
- **Lớp:** D25CQCC04-B
- **Học phần:** Lập trình hướng đối tượng (INT1332 - Nhóm 18)

## Cấu trúc thư mục
- `Cau1/Main.java`: Chuẩn hóa thông tin sinh viên (họ tên, ngày sinh).
- `Cau2/Main.java`: Tính học phí theo hệ đào tạo sử dụng lớp trừu tượng `SinhVien` và các lớp con (`CQ`, `CLC`, `LT`).
- `Cau3/Main.java`: Quản lý danh sách học phí với ngoại lệ tự định nghĩa `DuLieuKhongHopLeException` và lớp `QuanLyHocPhi`.
- `Cau4/Main.java`: Mở rộng chính sách miễn giảm học phí với interface `MienGiam` và thống kê theo từng hệ đào tạo.

## Hướng dẫn biên dịch và chạy chương trình

1. Mở terminal tại thư mục gốc của repository và vào thư mục câu cần chạy (`Cau1`, `Cau2`, `Cau3` hoặc `Cau4`): `cd Cau1`
2. Biên dịch file mã nguồn Java: `javac Main.java`
3. Chạy chương trình, nhập dữ liệu từ bàn phím (`System.in`) và nhấn Enter để xem kết quả: `java Main`[cite: 31, 32]
